🧮 Basic Calculator
A simple web-based calculator built to perform basic arithmetic operations like addition, subtraction, multiplication, and division. Perfect for quick calculations with a clean and intuitive interface.

# Author- Vicky Kuthe (web developer)
✨ Features

-Perform Addition, Subtraction, Multiplication, and Division
-Real-time result updates
-Clear and reset functions
-Responsive and user-friendly interface

🛠️ Tech Stack
-HTML
-CSS
-JavaScript
